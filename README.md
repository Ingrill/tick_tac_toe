# Guessing Numbers game (CLI)

A Python command-line interface (CLI) game. In which you can play Tick Tac Toe against a computer. Or watch 2 computers battle each other.

## 🛠️ Requirements

* **Python 3.7+**

## 📦 Installation

1. Clone or download this repository:

```bash
git clone https://github.com/Ingrill/tick_tac_toe.git
cd tick_tac_toe
```

## 💻 Usage

Run the script from your terminal.

### Syntax:

```bash
python game.py
```

## 📂 Project Structure

* `game.py` — Main CLI script logic.
* `player.py` — Defines player classes
